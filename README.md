# 朋友猜歌（YouTube 版）

一個放在 GitHub Pages 上的猜歌網頁，音源是 YouTube，流程參考 Muizo。不需要後端，朋友開網址就能玩。

## 兩種玩法

**四選一挑戰**
- 只聽音樂，四個選項選出歌名，有倒數計時。
- 答得越快分數越高：基本 60 分，加上最多 60 分的速度分，連續答對每多一題再加 8 分（最多加 10 次）。
- 答完後預設 4 秒自動換下一題，也可以按「下一題」、Enter 或空白鍵提前跳。

**搶唱派對**
- 畫面秀出歌名，最先唱出來的人按自己的按鈕搶答。
- 大家判定唱得對不對，需要時可以播原曲核對，並拖動時間軸（−10 / −5 / +5 / +10 秒、回到片段起點、從頭、方向鍵）。
- 可以各自用手機，或在同一個畫面上搶答，最多 8 人，按鈕排在畫面四周。

### 跟朋友玩：手機連線（PeerJS）

電腦（或投影到電視的畫面）當房主，朋友用自己的手機加入。搶唱派對和四選一都支援。
1. 首頁按「跟朋友玩」（或選題庫後在設定裡開房間），會產生 4 位數房號、QR Code 和加入連結。
2. 朋友掃 QR Code 或打開連結；也可以在首頁右上角按「加入房間」輸入房號和暱稱。
3. 房主選「搶唱派對」或「四選一多人」開始。遊戲中途也能加人（從 0 分開始），斷線重連會回到原本的位置和分數。最多 8 人，同螢幕玩家和手機玩家可混著玩。
4. 房主才會播放 YouTube，手機不用開聲音。

**搶唱派對**：手機是大大的搶唱鈕。唱對／唱錯可選「房主判定」，或「大家投票」（其他手機過半就定案，平手由房主決定，房主按鈕永遠優先）。

**四選一多人**：每人用手機同時作答，答得越快分數越高（基本 60 + 速度最多 60 + 連擊），全部答完就提前公布。房主可選擇「也一起玩」或「只當大螢幕」。設定裡可選「每題排行榜」（像 Kahoot，公布答案後秀出名次與升降）或「只在最後」公布。

## 設定

| 項目 | 說明 |
| --- | --- |
| 題數 | 每局幾首 |
| 作答時間 | 四選一每題的倒數秒數（10–40） |
| 選項顯示 | 四個選項上寫「歌名＋歌手」、「只顯示歌名」或「只顯示歌手」。答案公布和結果頁仍會顯示完整的歌名與歌手 |
| 公布答案 | 答完後停留幾秒再換題（2–15 秒） |
| 播放片段 | 隨機片段，或每首從頭開始 |
| 搶唱時間 / 獲勝條件 / 唱錯處理 | 只在搶唱派對出現 |

「選項顯示」選只顯示歌手時，同一位歌手的歌不會同時出現在四個選項裡。

## 建立題庫

**方法一：在網頁上貼連結（只存在自己的裝置）**
1. 在首頁點「貼上 YouTube 連結」。
2. 貼上播放清單網址（`youtube.com/playlist?list=…`），或一行一支影片。想自己寫歌名歌手，格式是 `歌名 | 歌手 | 影片連結`。
3. 歌名沒填的會從影片標題自動猜，猜錯可以回來按「編輯」修改。

限制：播放清單最多讀前 200 支，必須是公開或不公開的清單；私人清單與 YouTube 自動合輯（`list=` 後面是 `RD` 開頭）讀不到。

**刪除題庫（只影響這台裝置）**
- 點進題庫，按「刪除」（自己建的題庫）或「從這台裝置移除」（公開歌單），再按一次確定。
- 自己建的題庫刪掉就不見了；公開歌單只是在這台裝置上隱藏，別人看得到，也不會動到 `songs.txt`。
- 隱藏的公開歌單，可以在公開歌單頁最下面按「全部復原」。
- 「全部歌曲大混戰」是自動組合的，不能刪；被隱藏的歌單不會出現在裡面。

**方法二：寫進 `songs.txt`（所有人都玩得到）**
- 編輯 `songs.txt`，用 `[題庫名稱 | 標籤]` 開頭，底下一行一首「歌名 | 歌手」，也可以直接放影片或播放清單網址。
- 存檔後 GitHub Actions 會執行 `build-songs.js`：去 YouTube 搜尋、檢查能不能嵌入播放，然後更新 `songs-data.js`。
- 語法細節寫在 `songs.txt` 開頭的註解裡。

## 自動找歌時怎麼挑「原版」

`build-songs.js` 用「歌名 歌手」去 YouTube 搜尋，會幫候選影片打分數，盡量選原版：
- **加分**：標題有歌名、歌手；官方 MV；歌手自己的頻道、唱片公司頻道、YouTube 自動產生的「歌手 - Topic」。
- **扣分**：現場、演唱會、翻唱、伴奏、純音樂、remix；電視台與綜藝頻道（芒果TV、各家衛視、我是歌手、聲生不息等）；搬運號、歌詞號、KTV、合輯串燒、抖音版。
- 都找不到原版時，會退而求其次用扣過分但仍相符的影片，不會直接讓歌消失。
- 已經抓過、但來源是電視台或搬運號的歌，下一次執行時會自動重找一次；找不到更好的就維持原樣。
- 抓錯的歌，直接在 `songs.txt` 那一行填上影片連結（`歌名 | 歌手 | https://youtu.be/…`）就會優先採用，並且不會被自動換掉。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 新版遊戲，單一檔案 |
| `classic.html` | 舊版（Apple Music 音源），保留備用 |
| `vendor/` | PeerJS 與 QR Code 函式庫（本地放一份，連線不依賴第三方 CDN） |
| `songs.txt` | 題庫來源，手動編輯 |
| `songs-data.js` | 由 Actions 自動產生，不要手動改 |
| `build-songs.js` | 產生 `songs-data.js` 的腳本 |

## 鍵盤快捷鍵

- 四選一：`Q` `W` `A` `S` 或 `1`–`4` 選答案；`Enter` / 空白鍵 下一題。
- 搶唱：`1`–`8` 對應玩家搶答；`X` / Backspace 判唱錯；`P` 播原曲；`←` `→` 倒退或快轉 5 秒（加 Shift 為 10 秒）。

## 已知限制

- 有些影片不允許嵌入播放，遊戲會自動略過。
- 瀏覽器可能擋自動播放，第一次需要點一下畫面。
- iPhone Safari 對同時載入兩個影片比較嚴格，預載失敗時會退回正常載入，換題會慢一點。
- 排行榜只存在自己的裝置，沒有線上排行榜。
- 手機連線用 PeerJS 免費公開伺服器牽線，連上之後是點對點傳資料。少數網路（公司或學校 Wi-Fi、部分行動網路）擋 P2P，會連不上。
